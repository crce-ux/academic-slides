# talk-readiness

**学术汇报的「讲者侧」把关**

PPT 做得再好，**讲的人没内化，一样会当场卡住**。

---

## 它补的是哪半边

| 谁在管 | 管什么 |
|---|---|
| `ppt-master` / `nature-paper2ppt` 等 | **幻灯片本身**——版式、视觉、质检 |
| **本 skill** | **讲的人**——讲稿规格、待核清理、讲者是否真的懂了 |

两者**正交**，不重复。

---

## 三个核心

### 1. 待核清零

把 `待核 / ⏳ / 疑为 / 核不到 / 待补 / TODO` 扫成 **0**。

每一项只有两条路：**核到写实数**，或**删掉**。

> 🔴 **不允许「保留但标注待核」。**
> 这些是给自己的便签——跟着稿子走到台上，就是你当着所有人承认「这里我没查」。
> 而且念到它时的**停顿**比内容本身更显眼。

### 2. 讲稿规格

240 字/分钟、每页 200–500 字、**六样必带**（用时表 / 本页纪律 / 落点清单 /
主动交代清单 / 可压缩页含不可压页 / 页码对应）。

> ⚠️ **「不可压页」是关键**——只标可压缩页不够，
> **紧张时你会砍错地方，把核心结论砍掉。**

### 3. 理解确认四测试

| # | 测试 |
|---|---|
| 1 | **术语表**——全片术语，能一句不加术语的话解释 + 属性明确 |
| 2 | **数字表**——每个数字的口径 / 基准 / 量级感 |
| 3 | **追问清单**——8–12 个最可能被问的，**合上讲稿**答 |
| 4 | **逐页一句话**——翻开每页，合上讲稿说「这页在说什么」 |

**加上最快的一条**：

> 🔎 **磕巴判据**——把讲稿念一遍，**凡是念得磕巴的地方，就是没内化的地方**。
> 不需要任何表格，念一遍就知道。

---

## 还包含

- **版面算术预测**——画之前先算，特别是配图可读性判据 `图内字号 × 显示宽 ÷ 图宽 < 9px`
- **文献原图**——图注三样（出处 / 说什么 / 口径）；**贴图必须与文字换，不是加**
- **去味分力度**——表格数据不动、讲稿备注重改
