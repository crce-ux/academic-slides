# 讲稿规格与版面算术

## 一、待核清零

### 要扫的词

```
待核   ⏳   疑为   核不到   需回原文   待补   暂缺   TODO
```

### 两条路

| 路 | 做法 |
|---|---|
| **核到** | 写实数 + 出处 |
| **删掉** | 从稿子里去掉 |

> 🔴 **不允许「保留但标注待核」。**

这些待核标记是给自己的便签。**跟着稿子走到台上，就是你当着所有人承认「这里我没查」。**
而且念到它时的**停顿**比内容本身更显眼。

**也不允许用「一般认为」「据估计」洗白**——洗白等于把没查过的东西伪装成查过了。

## 二、讲稿规格

| 项 | 值 |
|---|---|
| 语速基准 | **240 字 / 分钟** |
| 每页字数 | **200–500 字** |
| 总字数 | = 目标时长(分钟) × 240 |

### 六样必带

1. **用时表**——每页多少秒
2. **每页本页纪律**——本页只说什么
3. **必须说出口的落点清单**
4. **主动交代清单**——短处自己先说
5. **可压缩页清单** + **标注不可压页**
6. **与内容稿页码对应**

> ⚠️ **第 5 项的「不可压页」是关键。**
> 只标可压缩页不够——**紧张时你会砍错地方，把核心结论砍掉。**

## 三、版面算术预测（画之前先算）

**不要等渲染出来才发现放不下。** 生成前先算。

### 整页容量

内容区固定尺寸下，按字号估字数：

```
容量 ≈ 内容区面积 × 0.78（损耗系数）÷ 单字占位
```

例（内容区 1200×525）：

| 字号 | 可容纳字数 |
|---|---|
| 18 px | ≈ 1123 |
| 20 px | ≈ 910 |
| 24 px | ≈ 632 |

### 区域带高

```
带高 = Σ ceil(该块字数 ÷ 每行字数) × 字号 × 行距
```

各带高之和 > 内容区高 → **画之前就该砍**。

### ⭐ 配图可读性判据

```
图内字号 × 显示宽 ÷ 图宽 < 9 px  →  不可读
```

**配图可读性判据最容易被忽略**：一张高清大图缩到版面上，图里的字可能只有 5 px。
**要计算，不能靠目测——在编辑器里缩放状态看不出来。**

## 四、版式选型（算完容量，再选配方）

**顺序固定，不要跳：**

```
① 算容量   slide_fit.py        放不放得下
② 选配方   pick_layout.py      这一页的内容形态像哪个版式
③ 取骨架   复制对应 SVG        填内容
```

### 32 个配方在哪

`references/layout-recipes.md`——7 套模板、6 份独立 deck、123 页全量扫读提炼出来的。
可直接复制的整页骨架在 `assets/skeletons/`（21 个 SVG），缩略图墙看 `assets/skeletons/_预览总表.png`。

### 正向：制作稿 → 候选配方

```bash
python scripts/pick_layout.py 制作稿.md --page P03
```

脚本只读**内容字段**（标题 / 页面文字 / 表格数据 / 图表说明），**不读「版式建议」**——
拿作者自己写的答案当输入就成了自问自答。输出三样：

| 输出 | 意思 |
|---|---|
| 形态 | 这一页有几个并列项、有没有表、几张图、几个数字 |
| 候选配方与命中理由 | 内容形态与配方的匹配，附「像」在哪 |
| 缺料 | 配方要 3 个数字、这一页只有 2 个 |

### 反向：配方回查制作稿

```bash
python scripts/pick_layout.py 制作稿.md --page P03 --recipe 17
```

指定配方，列出这一页**缺什么素材**。版面定不下来常常不是版式问题，是素材没凑齐。

### 制作稿写的「版式建议」与候选对不上

脚本会把「版式建议」里写到的配方号与候选比对。对不上有两种可能：

- 版式建议另有理由（这一页有别的约束）——照写，在制作稿里注一句为什么
- 内容形态与想用的版式不匹配——**以内容为准，改版式**

### 配方表自检

```bash
python scripts/pick_layout.py --audit
```

核对配方表与 `layout-recipes.md` 的编号集合是否一致、配方声明的骨架文件是否都在。

> ⚠️ 候选说明的是「像不像」，不是「该不该」。最终选型看这一页要说什么。

## 五、文献原图

- 每张图**图注必须写三样**：**出处** + **该图在说什么** + **口径**
- **贴图必须与文字换，不是加**

> 版面预算是固定的。加一张图，就要减掉相应的文字——
> 「加了图再挤一挤」的结果一定是溢出。

**筛选动作放在内容阶段**，不要等到做版面时才发现图不合适。

## 六、去味要分力度

| 部分 | 力度 | 理由 |
|---|---|---|
| **表格数据 / 口径提醒** | **不动** | 表格数据与口径提醒是事实，改一个字都可能出错 |
| 标题 / 页面文字 / 图注 | 轻改 | 书面表达，容错略高 |
| **讲稿备注** | **重改** | 要念出来的，口语化要求最高 |

**两条 PPT 专用豁免**：

- **加粗豁免**——每页加粗 **≤3 处**，只用于数字 / 效应量 / 方向词
- **并列半豁免**——并列项等长则打破；凑数的三连删到两条

---

## 七、九条质量界限（摘自实践）

1. 内容未定稿，**不做 PPT**
2. **数字不凭记忆**——每个都要回查
3. 导出后**必做视觉验证**
4. 去味**违反保真界限一律回退**——数字、单位、分母、方向词不得改动
5. 交付前**待核标记必须为 0**
6. 图注三样缺一不可
7. 贴图必须与文字换
8. 版面算不过就不要硬画
9. 讲稿念一遍不过关就不上台
